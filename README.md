Вариант 31. Этап 3. Виртуальная файловая система

Учебный проект на Python для практической работы ИКБО-66-25.
На этом этапе файловая система загружается из JSON в память программы.
Добавлена команда vfs-init для её сброса.

ЗАПУСК

Нужен Python 3.10 или новее. Дополнительные библиотеки не нужны.
Откройте PowerShell в папке stage3 и выполните:

    .\run.bat --vfs examples\vfs\deep.json

На Linux и macOS используйте sh run.sh --vfs examples/vfs/deep.json.
Если Python не найден, укажите путь к python.exe в переменной PYTHON_EXE.

НАСТРОЙКИ

--vfs задаёт JSON-файл. По умолчанию используется examples/vfs/minimal.json.
--script задаёт файл с командами для автоматического запуска.
--help показывает справку.

В стартовом скрипте комментарии начинаются с #, а пустые строки пропускаются.
Программа показывает выполняемые команды и их результаты.

ФАЙЛОВАЯ СИСТЕМА

JSON описывает виртуальные файлы и папки. Текст хранится в UTF-8,
двоичные данные — в base64. Данные загружаются в память без создания
реальных файлов и папок на компьютере.

В examples/vfs есть три примера:

minimal.json — пустой корень.
files.json — несколько файлов и папка.
deep.json — вложенные папки, включая /home/student/projects.

КОМАНДЫ

ls — выводит своё имя и аргументы.
cd — выводит своё имя и аргументы.
conf-dump — показывает настройки запуска.
vfs-init — очищает файловую систему в памяти и выбранный JSON-файл.
exit — завершает программу.

ls и cd на этом этапе ещё заглушки. Работа с файлами добавляется на этапе 4.
conf-dump, vfs-init и exit не принимают аргументы.

После vfs-init остаётся пустой корень. В JSON также записывается пустая
файловая система. Проверяйте эту команду на копии исходного файла.

ПРИМЕР

Внутри эмулятора введите:

    conf-dump
    ls /home
    cd /home/student
    unknown
    exit

Ошибочная команда выводит сообщение, после чего программа продолжает работу.

ПРОВЕРКА

Для демонстрации загрузки разных JSON и команды vfs-init выполните:

    .\scripts\check_vfs_a.bat
    .\scripts\check_vfs_b.bat

Эти скрипты создают копии JSON в папке work и сохраняют исходные примеры.
Они используют стартовый скрипт examples/scripts/stage3.txt.

Запуск тестов из папки stage3:

    python -m unittest discover -s tests -q

Если Python задан через PYTHON_EXE:

    & $env:PYTHON_EXE -m unittest discover -s tests -q

На этом этапе 20 тестов. При успешной проверке появляется OK.

СТРУКТУРА

src/__main__.py — запуск программы.
src/config.py — параметры запуска.
src/shell.py — обработка команд и стартовых скриптов.
src/vfs.py — загрузка JSON, проверка путей и сброс файловой системы.
tests — автоматические проверки.
examples — примеры JSON и стартовых скриптов.
scripts — проверки запуска с разными настройками и JSON.
run.bat и run.sh — файлы запуска.
