Вариант 31. Этап 4. Основные команды

Учебный проект на Python для практической работы ИКБО-66-25.
На этом этапе ls и cd работают с виртуальными файлами и папками.
Добавлены чтение файлов через cat и история команд через history.

ЗАПУСК

Нужен Python 3.10 или новее. Дополнительные библиотеки не нужны.
Откройте PowerShell в папке stage4 и выполните:

    .\run.bat --vfs examples\vfs\deep.json

На Linux и macOS используйте sh run.sh --vfs examples/vfs/deep.json.
Если Python не найден, укажите путь к python.exe в переменной PYTHON_EXE.

НАСТРОЙКИ

--vfs задаёт JSON-файл. По умолчанию используется examples/vfs/minimal.json.
--script задаёт файл с командами для автоматического запуска.
--help показывает справку.

В скриптах поддерживаются пустые строки и комментарии после #.
Выполняемые команды и их результаты выводятся на экран.
Если скрипт содержит exit, программа завершится.

КОМАНДЫ

ls — показать файлы и папки. ls -a также показывает скрытые имена.
cd — перейти в папку. Без пути возвращает в корень, cd - — в предыдущую папку.
cat — прочитать файл. cat -n добавляет номера строк.
history — показать историю. history N показывает последние N команд.
history -c — очистить историю.
conf-dump — показать настройки запуска.
vfs-init — очистить виртуальную файловую систему и её JSON-файл.
exit — выйти из программы.

В путях используются /, . и .., а ~ обозначает корень.
ls и cat принимают несколько путей. Перед именем с начальным дефисом
ставится --. conf-dump, vfs-init и exit не принимают аргументы.
В историю попадают также ошибочные команды и сам вызов history.

ПРИМЕР

Внутри эмулятора введите:

    ls
    cd /home/student/projects
    cat readme.txt
    cd ..
    history
    exit

Для проверки ошибки можно ввести cd /missing.
Программа сообщит, что папка не найдена, и продолжит работу.

Команды работают с данными в памяти и сохраняют исходный JSON.
Исключение — vfs-init: он также очищает JSON-файл.
Для проверки сброса используйте копию файловой системы.

ПРОВЕРКА

Полная демонстрация команд и ошибок:

    .\scripts\demo_stage4.bat

Скрипт создаёт копию JSON в папке work и сохраняет исходный пример.
Команды демонстрации находятся в examples/scripts/stage4.txt.

Запуск тестов из папки stage4:

    python -m unittest discover -s tests -q

Если Python задан через PYTHON_EXE:

    & $env:PYTHON_EXE -m unittest discover -s tests -q

На этом этапе 31 тест. При успешной проверке появляется OK.

СТРУКТУРА

src/__main__.py — запуск программы.
src/config.py — параметры запуска.
src/shell.py — ввод и выполнение команд.
src/commands.py — обработка флагов и нумерация строк.
src/vfs.py — виртуальные файлы, папки и работа с путями.
tests — автоматические проверки.
examples — примеры JSON и стартовых скриптов.
scripts — демонстрации и проверки запуска.
run.bat и run.sh — файлы запуска.

Ввод разбирается по пробелам. Кавычки, конвейеры и перенаправления
не поддерживаются.
