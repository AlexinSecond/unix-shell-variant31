Вариант 31. Этап 2. Настройки запуска

Учебный проект на Python для практической работы ИКБО-66-25.
На этом этапе добавлены параметры запуска, выполнение команд из файла
и команда conf-dump. Сохранены возможности первого этапа.

ЗАПУСК

Нужен Python 3.10 или новее. Дополнительные библиотеки не нужны.
Откройте PowerShell в папке stage2 и выполните:

    .\run.bat --vfs examples\vfs\minimal.json

На Linux и macOS используйте sh run.sh --vfs examples/vfs/minimal.json.
Если Python не найден, укажите путь к python.exe в переменной PYTHON_EXE.

НАСТРОЙКИ

--vfs задаёт путь к JSON-файлу. По умолчанию используется examples/vfs/minimal.json.
На этом этапе путь только сохраняется в настройках. JSON ещё не загружается.
--script задаёт файл с командами для автоматического запуска.
--help показывает справку.

При запуске выводятся настройки vfs_path и script_path.
Пути относятся к файлам на компьютере. Пути с пробелами заключайте в кавычки.

КОМАНДЫ

ls — выводит своё имя и аргументы.
cd — выводит своё имя и аргументы.
conf-dump — показывает настройки запуска.
exit — завершает программу.

ls и cd пока являются заглушками. conf-dump и exit не принимают аргументы.

ПРИМЕР

Внутри эмулятора введите:

    conf-dump
    ls /home
    cd /tmp
    unknown
    exit

Неизвестная команда выводит ошибку, после которой программа продолжает работу.

СТАРТОВЫЙ СКРИПТ

Для автоматической демонстрации выполните в PowerShell:

    .\run.bat --vfs examples\vfs\minimal.json --script examples\scripts\stage2.txt

В скрипте комментарии начинаются с #. Пустые строки пропускаются.
На экране видны выполняемые команды и их результаты.
Если встречается exit, программа завершается. Иначе после скрипта
можно продолжить вводить команды вручную.

ПРОВЕРКА

Проверка параметров запуска:

    .\scripts\check_parameters_a.bat
    .\scripts\check_parameters_b.bat

Запуск тестов из папки stage2:

    python -m unittest discover -s tests -q

Если Python задан через PYTHON_EXE:

    & $env:PYTHON_EXE -m unittest discover -s tests -q

На этом этапе 12 тестов. При успешной проверке появляется OK.
В демонстрациях некоторые команды специально вызывают ошибки.

СТРУКТУРА

src/__main__.py — запуск программы и стартового скрипта.
src/config.py — параметры запуска.
src/shell.py — ввод, выполнение команд и conf-dump.
tests — автоматические проверки.
examples — пример JSON и стартовый скрипт.
scripts — проверки параметров запуска.
run.bat и run.sh — файлы запуска.

Ввод разбирается по пробелам. Кавычки внутри команд эмулятора,
конвейеры и перенаправления не поддерживаются.
