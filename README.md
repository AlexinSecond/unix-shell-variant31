Вариант 31. Этап 1. Ввод команд

Учебный проект на Python для практической работы ИКБО-66-25.
На этом этапе создан простой консольный эмулятор UNIX-оболочки.
Программа принимает команды и показывает результат их выполнения.

ЗАПУСК

Нужен Python 3.10 или новее. Дополнительные библиотеки не нужны.
Откройте PowerShell в папке stage1 и выполните:

    .\run.bat

На Linux и macOS используйте sh run.sh.
Если Python не найден, укажите путь к python.exe в переменной PYTHON_EXE.

После запуска появится приглашение username@hostname:~$.
Имя пользователя и компьютера берутся из операционной системы.
Вводите только команду, без текста приглашения.

КОМАНДЫ

ls — выводит своё имя и переданные аргументы.
cd — выводит своё имя и переданные аргументы.
exit — завершает программу. Аргументы не принимает.

Команды ls и cd пока являются заглушками. Они не показывают файлы
и не меняют папку.

ПРИМЕР

Внутри эмулятора введите:

    ls -a /home
    cd /tmp
    unknown
    exit

Первые две команды покажут свои аргументы.
Для unknown появится сообщение command not found.
Пустой ввод игнорируется, ошибочная команда не завершает программу.
Ctrl+C отменяет ввод. На Windows Ctrl+Z и Enter завершают программу,
на Linux и macOS для этого используется Ctrl+D.

ПРОВЕРКА

Запуск тестов из папки stage1:

    python -m unittest discover -s tests -q

Если Python задан через PYTHON_EXE:

    & $env:PYTHON_EXE -m unittest discover -s tests -q

На этом этапе 6 тестов. При успешной проверке появляется OK.

СТРУКТУРА

src/__main__.py — запуск программы.
src/shell.py — приглашение, разбор ввода и обработка команд.
tests — проверки ввода, ошибок и завершения программы.
run.bat и run.sh — файлы запуска.

Команда и аргументы разделяются по пробелам. Кавычки и перенаправления
не поддерживаются.
