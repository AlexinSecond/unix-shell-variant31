# Эмулятор UNIX-оболочки — вариант 31

Учебный проект на Python для практической работы ИКБО-66-25.

Программа позволяет вводить команды и работать с виртуальными файлами и папками. Файловая система загружается из JSON.

## Запуск

Нужен Python 3.10 или новее. Дополнительные библиотеки не требуются.

Откройте PowerShell в папке проекта и выполните:

powershell
.\run.bat --vfs examples\vfs\deep.json


После запуска появится приглашение:

text
username@hostname:~$


Теперь можно вводить команды эмулятора.

Если Windows не находит Python, задайте полный путь к `python.exe` в переменной `PYTHON_EXE`.

На Linux и macOS запуск выполняется через:

bash
sh run.sh --vfs examples/vfs/deep.json


## Настройки запуска

- `--vfs` — путь к JSON-файлу с виртуальной файловой системой. По умолчанию используется `examples/vfs/minimal.json`.
- `--script` — путь к файлу с командами, которые выполняются при запуске.
- `--help` — справка по параметрам.

Пример запуска со скриптом:

powershell
.\run.bat --vfs examples\vfs\deep.json --script examples\scripts\quick_demo.txt


В скриптах поддерживаются пустые строки и комментарии после `#`. Выполняемые команды и их результаты выводятся на экран. Если скрипт содержит `exit`, программа завершится.

## Команды

| Команда | Что делает |
|---|---|
| `ls [PATH]` | Показывает файлы и папки. `-a` включает скрытые имена |
| `cd [PATH]` | Переходит в папку. Без пути возвращает в корень, `cd -` — в предыдущую папку |
| `cat FILE...` | Выводит содержимое файлов. `-n` добавляет номера строк |
| `history` | Показывает историю команд |
| `history N` | Показывает последние N команд |
| `history -c` | Очищает историю |
| `touch FILE...` | Создаёт пустые файлы или обновляет время существующих. `-c` запрещает создание новых |
| `conf-dump` | Показывает параметры запуска |
| `vfs-init` | Очищает виртуальную файловую систему и её JSON-файл |
| `exit` | Завершает программу |

В путях используются `/`, `.` и `..`. Символ `~` обозначает корень виртуальной файловой системы.

Для `ls`, `cat` и `touch` можно передать несколько путей. Перед именем с начальным дефисом используется `--`, например:

text
touch -- -note.txt


## Пример работы

После запуска с `deep.json` введите:

text
ls
cd /home/student/projects
cat readme.txt
touch note.txt
ls
history
exit


Команда `touch` изменяет файлы только в памяти. После перезапуска созданный файл исчезнет, а исходный JSON останется прежним.

Команда `vfs-init` также очищает JSON-файл. Для её проверки используйте копию файловой системы.

## Демонстрация

Полная демонстрация команд и обработки ошибок:

```powershell
.\scripts\demo_stage5.bat
```

Скрипт создаёт копию VFS в папке `work`, поэтому исходный пример сохраняется. Некоторые команды специально вызывают ошибки для проверки их обработки.

## Тесты

Запустите из папки проекта:

```powershell
python -m unittest discover -s tests -q
```

Если Python задан через `PYTHON_EXE`:

```powershell
& $env:PYTHON_EXE -m unittest discover -s tests -q
```

В проекте 45 тестов. Они проверяют команды, параметры запуска, пути, загрузку JSON и сохранность исходных файлов. Успешная проверка заканчивается строкой `OK`.

## Этапы работы

1. **Ввод команд:** консольный интерфейс, приглашение с именем пользователя и компьютера, заглушки `ls` и `cd`, команда `exit`.
2. **Настройки:** параметры запуска, стартовые скрипты и `conf-dump`.
3. **Файловая система:** загрузка JSON в память, двоичные данные в base64 и команда `vfs-init`.
4. **Основные команды:** реализация `ls`, `cd`, `cat` и `history`.
5. **Дополнительная команда:** реализация `touch`.

## Структура проекта

- `src/__main__.py` — запуск программы.
- `src/config.py` — обработка параметров.
- `src/shell.py` — ввод и выполнение команд.
- `src/commands.py` — обработка флагов и нумерация строк.
- `src/vfs.py` — виртуальные файлы, папки и работа с путями.
- `tests/` — автоматические проверки.
- `examples/` — примеры файловых систем и стартовых скриптов.
- `scripts/` — скрипты проверки и демонстрации.
- `run.bat`, `run.sh` — запуск проекта.

Парсер разделяет команды и аргументы по пробелам. Кавычки, конвейеры и перенаправления не поддерживаются. Ошибочные команды выводят сообщение, после чего программа продолжает работу.
